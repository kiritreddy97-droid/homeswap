# HomeSwap India: Cloud Setup

Everything is designed to run in the cloud, not on a laptop.

## 1. Develop in the cloud (GitHub Codespaces)
Push this repo to GitHub, open it in a Codespace. `.devcontainer/devcontainer.json` installs dependencies automatically. Run:
```bash
cd backend && uvicorn app.main:app --reload
```

## 2. Test in the cloud
`.github/workflows/ci.yml` runs lint, tests, a Postgres migration check and a Docker build on every push and pull request.

## 3. Deploy in the cloud (Render, free tier to start)
1. Push to GitHub.
2. In Render choose New > Blueprint and select the repo. `render.yaml` creates the API (from the Dockerfile) and a Postgres database.
3. In the Render dashboard set `ADMIN_CONTACTS` (your email or +91 number) and, once you have a KYC provider, `KYC_WEBHOOK_SECRET`. `JWT_SECRET` is generated by Render. Never commit these.
4. Open `https://<service>.onrender.com/docs`. Log in via `POST /auth/otp/request` and `/auth/otp/verify`; while `OTP_SENDER=console` the code appears in the service logs (staging only).
5. To go to production: implement an SMS/email `OtpSender` in `backend/app/otp.py`, set `OTP_SENDER` to it and `ENV=production`. The app refuses to start in production with the default JWT secret or the console sender.

Migrations run automatically on each start (`alembic upgrade head` in the Dockerfile).

Alternatives: Fly.io, Railway, Google Cloud Run (image from the Dockerfile) or AWS App Runner. Set `DATABASE_URL` from the managed Postgres.
